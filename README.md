## Описание проекта

Двумерная аркадная игра «Астероиды» на `pygame-ce`. Игрок управляет
космическим кораблём, который может вращаться, ускоряться и стрелять
ракетами по астероидам. Игровое поле имеет тороидальную геометрию:
объекты, выходящие за границу экрана, появляются с противоположной
стороны. Реализованы анимация двигателя, анимация взрыва, статичный
и динамический фон, система жизней и очков.

## Функциональные возможности

### Основной функционал

- Управление кораблём: вращение, ускорение, стрельба
- Тороидальная геометрия игрового поля
- Случайный спавн астероидов со случайной линейной и угловой скоростью
- Смена спрайта корабля при включённом двигателе (пламя)
- Сопротивление среды при выключенном двигателе
- Ограниченное время жизни ракет
- Столкновения: пуля–астероид, корабль–астероид
- Анимация взрыва
- Система жизней (3 на старте) и очков
- Экран старта: клик только по центральной заставке запускает игру
- Экран Game Over: возврат к заставке с сохранением счёта и жизней
- Астероиды не сталкиваются между собой

## Требования к системе

- **Python:** 3.10 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:**
  - `pygame` 
- **Ассеты:** папка `assets/images/` должна содержать спрайты
  (`playerShip3_green.png`, `fire03.png`, `meteorBrown_med1.png`)

## Установка и запуск

### 1. Клонирование репозитория
git clone 'https://github.com/kamillka26/game_asteroids'
cd asteroids
### 2. Создание и активация виртуального окружения
Windows:

python -m venv venv
source venv/Scripts/activate

macOS/Linux:

python3 -m venv venv
source venv/bin/activate
### 3. Установка зависимостей
pip install -r requirements.txt
### 4. Запуск программы
python main.py
### 5. Управление
← / → - Вращение корабля
↑ - Двигатель (ускорение)
Space - Выстрел ракетой
Клик по заставке - Начать игру
